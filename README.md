# dak2.com

個人サイト。ブログ・スクラップ・読書感想・経歴・SNS リンクを雑多にまとめる。

## 設計メモ

- **フレームワーク**: Next.js
- **テーマ**: [tailwind-nextjs-starter-blog](https://github.com/timlrx/tailwind-nextjs-starter-blog) をベースに拡張予定
- **ホスティング**: Vercel（Hobby プラン、無料）
- **ドメイン**: dak2.com

## コンテンツ構成（URL 分離方式）

- `/blog/*` — ブログ記事
- `/scraps/*` — 思考の断片
- `/reviews/*` — 記事を読んだ感想
- `/about` — 経歴・SNS リンク
